Casa Hoy Solidez Total es una empresa real de venta de casas prefabricadas con placas premoldeadas de hormigón.

CasaHoy App es una plataforma orientada al primer contacto entre la empresa y los clientes.
El sistema busca ofrecer una experiencia más cálida, visual e intuitiva durante la búsqueda de viviendas, reemplazando interfaces frías y poco personalizadas como chatbots por recorridos guiados con imágenes, videos y mensajes amigables.

La aplicación permite:

- Gestionar viviendas
- Crear experiencias de bienvenida
- Mostrar recursos visuales
- Guiar clientes mediante preguntas
- Registrar consultas e intereses

Objetivo del proyecto
Desarrollar un sistema utilizando:

Arquitectura Limpia (Clean Architecture)
TDD (Test Driven Development)
TypeScript
Node.js
Monorepo

El proyecto separa claramente:

Dominio
Backend
Frontend

para mantener un código desacoplado, mantenible y escalable.

Problema que busca resolver

Muchos sistemas inmobiliarios actuales presentan:

- Interfaces frías y automatizadas
- Demasiada información técnica
- Experiencias poco humanas
- Falta de guía para clientes

CasasHoy App propone una experiencia de primer contacto más cercana y guiada, ayudando al usuario a sentirse acompañado durante la búsqueda de una vivienda.

Arquitectura

El proyecto sigue principios de Clean Architecture:

Entidades independientes
Casos de uso desacoplados
Repositorios abstractos
Separación entre dominio e infraestructura

Además, el desarrollo se realiza utilizando TDD para garantizar:

Código confiable
Mayor mantenibilidad
Mejor diseño del dominio
